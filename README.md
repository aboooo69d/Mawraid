# موارد – واجهة المواطن (Mobile-first v1)

نسخة مطوّرة من ملفات UI_Mawarid المرفقة، وليست إعادة تصميم.

## التشغيل

```bash
npm install
npm run dev
```

افتح http://localhost:3000. لنشر النسخة، اربط المستودع مع Vercel بعد اختبارها.

## ما تم
- إزالة عرض الهاتفين المتجاورين؛ شاشة واحدة على كل الأجهزة.
- البداية من الرئيسية، وتنقل عربي RTL.
- رحلة طلب غاز تجريبية: الرئيسية ← طلب الغاز ← تأكيد تجريبي ← عرض حالة الطلب.
- نشاط فارغ قبل تسجيل طلب، ورقم طلب محلي مميز لكل عملية.
- تعطيل خدمة الماء مؤقتًا ليتطابق النموذج الأولي مع Sprint 1.
- عدم الادعاء بتتبع مندوب أو حجز مخزون أو وجود محفظة متصلة.

## حدود النسخة
هذه واجهة **تجريبية فقط**؛ الطلبات محفوظة في ذاكرة الصفحة حتى إعادة التحميل، ولا توجد API أو مصادقة أو قاعدة بيانات متصلة. الأسعار والأحياء الظاهرة بيانات توضيحية وليست معلومات إنتاجية مؤكدة. الملف ERD 2.drawio.svg مرجع مستقل ولا يعني وجود تنفيذ خلفي.

## المرحلة التالية
ربط API للطلب وstock reservation وتوثيق الحالات، ثم شاشات الوكيل حسب المسارات المعتمدة.
