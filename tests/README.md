# 🧪 دليل وبنية اختبارات النظام (Test Suite Documentation)

يحتوي هذا المجلد الرئيسي (`tests/`) على جميع حالات الاختبار (Test Cases) الخاصة بنظام **Mawraid API**، وهي مقسمة بشكل منهجي داخل مجلدات متخصصة بحسب النطاق الوظيفي (Domain / Topic)، مع عزل كل حالة ومسار اختبار داخل ملف مستقل.

---

## 📁 هيكلية مجلد الاختبارات (Directory Structure)

```
tests/
├── README.md                      # دليل وهيكلية الاختبارات
├── auth/                          # اختبارات المصادقة وإدارة الحسابات
│   ├── mocks_test.go              # كائنات المحاكاة (Mocks & In-memory Repositories)
│   ├── login_test.go              # حالات اختبار تسجيل الدخول وفحص الحالات
│   ├── register_consumer_test.go  # حالات اختبار تسجيل المستهلكين
│   ├── register_provider_test.go  # حالات اختبار تسجيل مزودي الخدمات
│   ├── otp_test.go                # حالات اختبار رموز التحقق والـ Cooldown
│   └── password_reset_test.go     # حالات اختبار استعادة وتعيين كلمة المرور
├── middleware/                    # اختبارات الوسائط البرمجية (Middlewares)
│   ├── turnstile_test.go          # حالات اختبار التحقق من Cloudflare Turnstile
│   ├── session_test.go            # حالات اختبار الجلسات ورفض غير المصرح لهم (401)
│   └── error_handler_test.go      # حالات اختبار المعالج العام للأخطاء
├── crypto/                        # اختبارات التشفير والتجزئة الأمنية
│   ├── encryption_test.go         # حالات اختبار تشفير وفك تشفير AES-256-GCM
│   └── hashing_test.go            # حالات اختبار تجزئة كلمات المرور عبر Bcrypt
├── storage/                       # اختبارات التخزين السحابي وفحص الملفات
│   └── file_validation_test.go    # حالات اختبار التحقق من أحجام وأنواع الملفات
└── validator/                     # اختبارات قواعد التحقق والمدخلات
    └── yemen_phone_test.go        # حالات اختبار أرقام الهواتف اليمنية وتوافق الشبكات
```

## 🎯 تفاصيل حالات الاختبار حسب النطاق

### 1. المصادقة والحسابات (`tests/auth/`)
* **`login_test.go`**:
  * فحص رفض رقم الهاتف غير المسجل (`404 Phone Not Found`).
  * فحص رفض كلمة المرور الخاطئة (`401 Invalid Credentials`).
  * فحص منع الدخول للحساب غير المؤكد (`403 Account Not Verified`).
  * فحص منع الدخول للحسابات ذات الحالات: `pending`، `docs`، `rejected`، `suspended`.
  * التحقق من نجاح تسجيل دخول الحساب النشط والمؤكد.
* **`otp_test.go`**:
  * فحص تفعيل الـ Cooldown (الانتظار دقيقة بين كل طلب).
  * فحص الحد الأقصى اليومي لطلب الرموز (5 طلبات يومياً).
  * فحص الحد الأقصى لمحاولات الإدخال الخاطئة (3 محاولات).
  * فحص خطأ تعطل مزود الـ SMS (`500 Internal Server Error`).
  * نجاح التحقق عند مطابقة الرمز.
* **`register_consumer_test.go`** & **`register_provider_test.go`**:
  * منع التسجيل برقم هاتف مسجل مسبقاً (`409 Conflict`).
  * التحقق من تهيئة الحساب الجديد كـ `is_verified: false`.
* **`password_reset_test.go`**:
  * منع تسريب وجود المستخدم عند طلب استعادة كلمة المرور (Anti-Enumeration).
  * منع استعادة كلمة المرور للحسابات المجمدة (`suspended`).

---

### 2. الوسائط البرمجية (`tests/middleware/`)
* **`turnstile_test.go`**:
  * التحقق من حظر الطلب بكود `403 Forbidden` عند غياب ترويسة التوكن (والتأكد من عدم حدوث Panic).
  * فحص رفض التوكن إذا تجاوز الحد الأقصى المسموح للحجم.
  * فحص رفض الطلب عند غياب الإعدادات.
* **`session_test.go`**:
  * فحص إرجاع كود `401 Unauthorized` القياسي عند غياب الجلسة.
  * فحص تمرير الطلب وحقن بيانات `user_id` و `role` في الـ Context عند وجود جلسة صالحة.
* **`error_handler_test.go`**:
  * تمرير الطلبات الناجحة دون تعديل.
  * تحويل أخطاء التطبيق (`AppError`) إلى استجابة JSON متوافقة مع الكود وحالة HTTP المحددة.
  * تحويل أي خطأ غير معالج إلى استجابة `500 Internal Server Error`.

---

### 3. التشفير والتجزئة (`tests/crypto/`)
* **`encryption_test.go`**:
  * التحقق من نجاح دورة التشفير وفك التشفير بـ AES-256-GCM.
  * التأكد من عدم احتواء النص المشفر على أي بيانات صريحة.
  * فشل فك التشفير عند استخدام مفتاح غير صحيح أو في حال التلاعب بالنص المشفر (Tampered).
  * رفض التشفير عند تمرير مفتاح لا يساوي 32 بايت.
* **`hashing_test.go`**:
  * التحقق من مطابقة الهاش لكلمة المرور الأصلية وفشله مع الكلمات الخاطئة.
  * التحقق من توليد Salting مختلف لكل عملية تشفير لنفس كلمة المرور.

---

### 4. التخزين وقواعد التحقق (`tests/storage/` & `tests/validator/`)
* **`file_validation_test.go`**:
  * رفض الملفات التي تتجاوز الحد الأقصى (5MB).
  * رفض أنواع الملفات غير المصرح بها والسماح فقط بالصور وPDF.
* **`yemen_phone_test.go`**:
  * اختبار أرقام شركات الاتصالات اليمنية (يمن موبايل 77، يو 73، سبأفون 71، واي 70، و 78).
  * رفض الأرقام القصيرة، الطويلة، أو المحتوية على أحرف أو رموز خاصة.

## 🚀 كيفية تشغيل الاختبارات (Running the Tests)

لتشغيل جميع الاختبارات في كامل المشروع:
```bash
go test -v ./tests/...
```

لتشغيل مجلد معين (مثال: اختبارات المصادقة):
```bash
go test -v ./tests/auth/...
```

لتشغيل ملف اختبار أو دالة محددة:
```bash
go test -v ./tests/crypto/ -run TestAES256GCMEncryption
```
